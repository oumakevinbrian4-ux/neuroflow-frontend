# Nueraflow Frontend

React + TypeScript + Vite starter for the Nueraflow AI development workstation.

## Run

```bash
npm install
npm run dev
```

Set `VITE_NUERAFLOW_API_URL` to the backend URL (default `http://127.0.0.1:8000`). The first screen includes a working chat interface; research, projects and neuromorphic lab navigation are visual placeholders for later increments.

```bash
npm run build
```
